## 一、界面工程（都是踩出来的）

### 1.1 「设置改了但页面没变」= 静默失效，两个来源
1. **页面/VM 必须订阅偏好，不能只在 `load()` 里读一次**。课表页有「已是 Ready 就直接 return」的短路，
   而锚点只在 `load()` 里读一次 → 校准页三处证据（界面 / prefs / 日志）全对，课表页纹丝不动。
   正确做法：VM 里订阅 `settings.prefs`，值变了**就地重算派生状态**（锚点与网络无关，不该为了重算
   再打一遍接口）。守卫只比 `monday` + `source`，**不比 `savedAt`**（写入每次都盖新时间戳，比它会让
   「自己刚写的值」被当成「用户又改了一次」白重算一遍）。
2. **`Dispatchers.Main.immediate` 上写 StateFlow 会同步唤醒订阅者 → 嵌套重入写入**。
   `_prefs.value = next` 之后订阅者可能反手又写一次偏好，此时 `next` 已过期；若落盘写 `next` 就会把
   订阅者刚写的值覆盖回去。实测点「清除」后内存 `2026-08-31|exam`、磁盘被写成 null → 下次冷启动锚点
   凭空消失。**落盘一律写最新的 `_prefs.value`**。副作用：日志顺序会交错（嵌套的日志排在外层前面），
   不要据日志先后推断事件先后。

### 1.2 配置一律单例 + StateFlow
`SettingsRepository` / `SessionRepository` / `RushStore` 都是全局单例 + StateFlow，位置变化不影响订阅
（主题在 Activity 顶层、尺寸在课表页，各订阅一次）。**各建实例 = 「点了深色没反应，只有重启才生效」。**
- 偏好键**存字符串**（`system`/`light`/`dark`），不存枚举序号 —— 以后插模式不会把旧值读成另一个模式。
- 尺寸档：高度 52/58/64/70/76（默认 64）、列宽 62/68/74/80/86（默认 74），读入一律 `snap()` 吸附
  （容错旧值/脏值；距离相同取较小档）。
- **尺寸只有一个来源**（`TimetableSizeSpec` + `TimetableSize` 推导 pitch/字号/块位置），渲染与自检
  看同一份公式 → 不会出现「格子变了、字号没变」。设置子页的「实时预览」直接调课表真渲染器
  （`ui/timetable/TimetableCanvas.kt` 的 `WeekTable`）；预览高度是**算出来的**（`span×max(pitch)−gap`）。

### 1.3 课表行高：真空隙，不是「行高 = pitch」
底纹格与节次轴 = 每行 `periodHeightDp` + **`Arrangement.spacedBy(PERIOD_GAP)` 的真空隙**，
**不是**「行高 = pitchDp（行尾空隙算进行内）」。两种写法总高 / 轴总高 / 块底边落点全都相同
（所以只看外框的断言抓不出问题），但**可见矩形差一个 PERIOD_GAP** → 后者让每个课块底边下漏 3dp 底纹。
内缩量 `TimetableSizeSpec.CELL_INSET_DP`（底纹格与课块共用）。
**渲染侧「对齐」有外框与可见矩形两种口径**：只断言外框（如「块底 == rowBottomDp」）会放行整类缺陷；
凡涉及相邻元素贴边，必须比**内缩之后**的矩形。

### 1.4 课表滚动（两条都是踩出来的）
1. **节次轴必须跟内容一起纵向滚**。轴「固定不滚」时滚到下半段，第 7 节的行下面对着轴上的「5」
   —— 数字与内容错位，比看不见节次号更糟。做法：轴与网格放进**同一个纵向滚动容器**。
2. **横向与纵向要用父子嵌套容器，不能叠在同一个 Modifier 链上**。实测
   `.horizontalScroll(h).verticalScroll(v)` 叠在同一个 Row（且共享 state）时手势方向判定出错：
   横滚到右侧后上下滑纹丝不动，横向位置还被重置回周一。改为外层纵滚、网格内层横滚。
3. 表头纵向固定、横向与网格**共享同一个 ScrollState**（各用各的必然标题错位）；列宽 74dp、单节高 64dp
   —— 列宽固定后 7 列装不下，横向滚动是必需。
4. 尺寸可读性口径：手机窄列 40~50dp 时课名只能挤三四个字 → 别用 weight 均分 7 列。

### 1.5 深色配色不能靠「压暗浅色底」
浅色底是近白粉彩（三通道差异极小，有意为之）。压暗后十个颜色塌缩成一批深灰、肉眼分不出。
正确做法 = `mix(surface, accent, 0.35)` 从饱和 accent 混。量化口径（最小两两距离 ×1000）：
浅色 25 / 旧深色 **5** / 新深色 **39**（`ui/timetable/CoursePalette.kt` 带变异探针自检）。
- 判断深浅用 `colorScheme.background.luminance()`，**不要用 `isSystemInDarkTheme()`**
  （本应用允许强制深色，系统偏好与实际配色可以不一致）。
- 中性色恒定、只有强调色跟色相走；`surfaceTint` 必须显式 `Transparent`。
- **M3 baseline 是紫色的** —— `lightColorScheme()` 没传的角色会落回 `#6750A4` 系
  （踩过：底部导航栏永远淡紫，切任何主题它都不变）。

### 1.6 Kotlin 零警告的两个坑
- `"第$n周"` 里的「周」是合法标识符字符 → 被当成变量名（要写 `${n}`）。
- 智能转换让 `!fitsTerm && x != null` 报 `Condition is always 'true'`（`fitsTerm` 的定义里已蕴含
  `x != null`）→ 直接写 `!fitsTerm`。
- 改完 grep `\p{Han}` 与 `^w:` 复查。

## 二、分享 / 导出 .ics（2026-09-21 实测）

### 2.1 预检查询只能证伪、不能证实
想「先查有没有 App 能处理、没有就别说文件没生成」——两个坑都在这个查询上：
1. **`ChooserActivity` 会吞掉唯一候选**。MuMu 上导出一直弹系统「沒有應用程式可執行這項操作。」，
   但同一台设备 `am start -a android.intent.action.SEND -t text/calendar` **能正常解析并打开**
   `com.google.android.gms/nearby.sharing.send.SendActivity`。同一 intent：AMS 能解析、选择器说没有。
   → 改成**单候选直投、多候选才套 `Intent.createChooser`**（只有一个 App 能处理时本来也没有「选」的
   必要，这也是 Android 12 之前的行为）。改完处理者真的打开了，裸报错消失。
2. **Android 11+ 包可见性过滤**：不声明 `<queries>` 时 `queryIntentActivities` 恒为空 ——
   那会在**真有日历 App 的真机上反过来谎报「没有能打开 .ics 的应用」**。已按
   `SEND` + `text/calendar` 声明。这条比坑 1 隐蔽：MuMu 上「表现正常」（本来就该显示"没有"）。
   查询要带 `MATCH_DEFAULT_ONLY`，与 chooser 的解析口径对齐。
3. 候选逐个写进 `JxauLog`，App 内诊断页直接可查。

### 2.2 ICS 其它硬约束
- `UID` 必须是**短 ASCII 形态**：`exam-{学期码}-{课程代码}-{yyyyMMdd}-{HHmm}@jxau.tools`。
  第一版把「学期码 + 中文课程名」整体 `%XX` 转义 → 200 字符、**被折成三行**。UID 只用于去重、
  不是给人看的 → 只取本来就有 ASCII 形态的字段，课程代码缺失才退回课程名。
- 折行按 **octet**（75 字节）且**不能劈开 UTF-8 多字节**（切点落在续字节上就往前退）；CRLF；
  转义 `\` `;` `,` 换行（`\r` 直接丢）；`DTSTART` 用 **UTC**（中国无夏令时，避开 `VTIMEZONE`）。
- 时间解析：`KsSj` 里是 `晚上7：00-9：00` —— ⚠️ **全角冒号**必须收；中文时段词（`上午/下午/晚上/…`）
  要按「开始时刻之后」的位置找，否则 `上午11：00-1：00` 会把结束时刻算成 01:00。

## 三、本机工具链

- JDK17 `D:\IO\jdk17`；SDK `D:\IO\sdk`；Gradle 8.10.2 `D:\IO\gradle`；**adb 不在 PATH**，全路径
  `D:\IO\sdk\platform-tools\adb.exe`。**构建全程命令行，不用 Android Studio。**
- 依赖缓存缺 **WorkManager / DataStore** → 不用这两库（AlarmManager + 前台 Service + SharedPreferences）。
- 离线陷阱：**不能启用 `kotlin("plugin.serialization")`**（compiler plugin 未缓存），只能用运行时
  `Json.parseToJsonElement`；`okhttp-urlconnection` 未缓存 → CookieJar 自建。
- 增量 dex 报 `desugar_graph\...\graph.bin 拒绝访问`（Windows 文件锁 / 增量中间产物残留，**不是代码
  问题**；`compileDebugKotlin` 本身已过）→ `rm -rf app/build/intermediates/desugar_graph` 后重建。
- **Git Bash 里没有 `unzip`**：`unzip -oq` 会静默失败（`2>/dev/null` 吃掉报错），让「解 APK 数 dex
  里有没有新符号」变成**假通过** → 用 Python `zipfile` 读。
- MuMu 模拟器：`adb connect 127.0.0.1:7555`，900x1600 / density 320（450x800dp）。
  **每次 Bash 调用 adb daemon 都会重启 → `connect` 与命令必须在同一次调用里**，并带 `-s 127.0.0.1:7555`。
  本体 `D:\tools\MuMu`，启动 `D:/tools/MuMu/nx_main/MuMuManager.exe control -v 0 launch`（等约 1 分钟）。
- **模拟器访问宿主机用 `10.0.2.2`**（NAT 网关），不要用 `adb reverse` —— daemon 每次重连就清掉映射，
  演练跑到一半断连极难排查。
- 取会话：`adb shell run-as cn.edu.jxau.tools cat /data/data/.../shared_prefs/jxau_session.xml`
  → 把接口探测从「端上重编」搬到「本机 Python」（`tools/probe_pages.py`、`tools/probe_features.py`）。
- 日志 tag `JXAU_NET`（`JxauLog` 同时写 logcat 与 App 内诊断页）。偏好键分两个文件：
  `jxau_settings.xml`（theme_mode / color_theme / timetable_*）、`jxau_session.xml`（会话 + saved_at）。
  测试改过设置记得恢复原值。
- `adb ... > /tmp/x` 之后 **Windows 版 Python 读不到**（Git Bash 的 `/tmp` 与 Win32 路径不互通）→
  重定向写工作区内路径（如 `tools/out/ui.xml`）。
- UI 对账：`uiautomator dump /sdcard/ui.xml` → `cat`（设备 `/tmp` 不可写）；
  **按整段 `<node …>` 解析**，绝不用 `grep -oE … | paste - -`（会坐标错位）。
  Compose `Slider` **`input tap` 点不动，必须 `input swipe` 拖**，拖完先 dump 标签确认档位真变了。

## 四、工作约定

- **每轮实质改动落一次本地 git 提交**，中文信息写清「改了什么 + 为什么 + 怎么验证的」。
- **零警告零错误是底线**，不是努力目标。交付要给「改了什么、凭什么说它对了」，不要空泛说明。
- 不确定的事显式标注；发现旧文档 / 旧注释与现状不符**顺手改掉**。
- **App 级副作用不要挂在某个页面的 ViewModel 上**（会话有效时登录页根本不会被创建 → 永不执行）。
  自检挂 `MainActivity.onCreate`，不能只挂登录页 VM。
- **不要自己测自己**：关键纯逻辑用 Python 独立重算期望值再逐项对账。两个配套口径：
  ①对账模型必须**建模 Compose 的 8 位量化**（`Color(F,F,F)` 在 sRGB 下四舍五入）；
  ②**不要用肉眼估截图判断尺寸/位置变化**（74dp 与 86dp 在缩略图上差不到 10px）→ 写脚本量像素。
- **「不崩不报错、只是难看」的东西也要有断言**（对比度 / 两两距离 / 亮度关系），再加**变异探针**
  把旧实现固化成断言 —— 「现在是好的」不等于「坏的时候抓得住」。
- 验证「跟随系统」深色要**双向**（`adb shell cmd uimode night no|yes`），只验一边等于没验。
- 探测脚本里的**写操作黑名单（`WRITE_HINTS`）不要放宽**：`Save/Add/Del/Submit/Confirm…` 只登记不请求。
- **隐私**：学籍接口含身份证号 / 家庭住址 / 邮编 → 展示需脱敏、不落日志、不导出；
  探测产物 `tools/out/`（含个人数据）必须保持 gitignore。
