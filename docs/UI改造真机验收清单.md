## 1. P0 —— 课表 2dp 档位 · 12 主题 + 自定义色相 · 字号缩放

### 1-1 十二个主题色都真的生效（找「还是紫色的」漏网角色）★ 最重要

**操作**：我的 → **外观主题** → 「配色模式」切**浅色** → 「**主题色**」卡里依次点 **12 个色块**
（6 列 × 2 行：绯红/暖橙/琥珀/橄榄/草绿/竹青/翡翠/青碧/经典蓝/紫罗兰/品红/玫红），
每点一个截一张；再把「配色模式」切**深色**，重来一遍（共 24 张）。

**期望**：每次切完，**整屏**都跟着变 —— 特别是这四个最容易漏的地方：
底部导航栏底色与选中态、卡片标题与图标、`FilterChip` 与选中态按钮、进度条与开关轨道。

**不通过说明什么**：任何一个部件还是紫色 → 该处**没走 `MaterialTheme.colorScheme`，
是硬编码或 M3 baseline 泄漏**。这正是上一轮「底部导航一直淡紫」那类缺陷的同类。
反馈请报「色块名 + 浅/深 + 哪个部件」，并附截图。

### 1-2 自定义色相滑块

**操作**：我的 → 外观主题 → 「**自定义色相**」卡 → ① 点色相带上任意一段；② 拖下方滑块；
③ 换三档饱和度（柔和/标准/浓郁）；④ 最后点右侧「**使用**」。

**期望**：
- 拖动/点选时，卡片上方那个**预览圆**与「色相 xxx° · 档位」文字**实时**跟着变；
- 点「使用」之后是**整个界面**（含底部导航）才跟着变 —— 启用是**显式**的，不是拖完自动生效
  （防止用户拖的过程中界面乱闪）；
- 重新进这个页面时，滑块停在你上次的位置，且预览圆上带 ✓ 表示正在使用中。

**不通过说明什么**：拖滑块时预览圆也不动 → `rolesForHue` 实时预览链路断了；
点「使用」后界面不变 → `customAccent` 没传进派生链路（会回落成默认浅蓝，
界面表现为「选了没反应」）；重进页面回跳 → 落盘的不是最新值。

### 1-3 字号 4 档：界面文字变、**课表字号必须不变**

**操作**：我的 → **字体** → 「**字号缩放**」→ 依次选 小 / 标准 / 大 / 特大，每次回课表页看一眼。

**期望**：界面文字（标题、列表、按钮、以及同页「预览」卡）跟着缩放；
**课表格子里的课程名字号不动**。

**不通过说明什么**：课表字号也变了 → 有人把全局缩放接到了 `LocalDensity.fontScale`
（会撞「字撑破格子」）。这是**刻意写成规格断言**的一条：课表字号由列宽推导，不跟全局缩放。

### 1-4 字族 3 档

**操作**：我的 → **字体** → 「**字族**」→ 默认 / 衬线 / 等宽。

**期望**：「默认」是黑体；衬线/等宽**若系统支持**则中文变字形。**中文回落黑体不是 bug**
（部分 ROM 没有中文衬线/等宽字面），页面文案已经写了「若系统支持」。

**不通过说明什么**：三档完全无差别**且**英文/数字也没变 → 字族没接上；只有中文没变 = 正常。

### 1-5 课表尺寸两端档位（列宽 48dp / 104dp，行高 40dp / 100dp）

**操作**：我的 → **课表显示** → 「**格子尺寸**」→ 把行高和列宽都拖到**最小**（页面上有实时预览），
回课表页截图；再拖到**最大**，截图。

**期望**：横向能平滑滚到最左/最右，最右一列**完整可见**（不是被切一半）；
表头周几与下面的课程列**始终对齐**（滚到两端也对齐）；行高变化时底纹格与课块**不留缝**。

**不通过说明什么**：末端列错开 → 表头与网格两条渲染路径的**总宽**算得不一致；
块下方露一条背景 → 课块可见矩形与底纹格不等（`CELL_INSET_DP` 那条对齐关系）。

**顺带**：这 4 张截图正好喂给 4 个像素脚本（**脚本不用改，截图要重截**）：

```bash
python tools/measure_timetable_geometry.py tools/out/p0_w_min.png tools/out/p0_w_max.png
python tools/measure_timetable_columns.py  tools/out/p0_w_min.png --colw=48
python tools/measure_block_fit.py          tools/out/p0_w_max.png
python tools/measure_stripe_contrast.py    tools/out/p0_tt_light.png tools/out/p0_tt_dark.png
```

> 它们的期望值来自 `TimetableSurface.kt`（本轮未动），所以**档位加密不影响脚本**；
> 影响的是**截图坐标基准**，所以要重截。这 4 个脚本对本轮改动的判别力有限，
> 不能拿它们当验收 —— 它们的用途是「回归：尺寸改了但渲染没跟上」。

### 1-6 杀进程重启后设置仍在

**操作**：把设置改成非默认（比如主题「翡翠」+ 字号「大」+ 行高 82dp）→ 从最近任务划掉 →
重新打开。

**期望**：三项都还在。

**不通过说明什么**：回默认值 → 落盘失败或读取时键名/默认值不匹配。

## 2. P1 —— 控件归位

### 2-1 登录页「访问通道」是三段，不是三个圆点

**操作**：登录页第一张卡。

**期望**：一行三个**连通的分段**（自动 / 直连 / WebVPN），选中的那段有填充色，
整段可点；**点哪段立即生效**（不用点「确定」）。

**不通过说明什么**：还是三个 RadioButton 圆点 → 装的是旧包（回 0-1 重查）。

### 2-2 外观主题页「配色模式」也是分段（不是竖排单选）

**操作**：我的 → 外观主题 → 配色模式。

**期望**：系统 / 浅色 / 深色 三段一行；**当前项的说明文字在下面单独一行**，
切段时说明文字跟着换。切到「浅色/深色」应立即改变整个界面。

### 2-3 两个开关：**点整行任意位置都能切** ★ 容易只测到一半

**操作**：
- ① 登录页「记住密码」那一行 —— 点文字、点开关、点**两者之间的空白**；
- ② 我的 → 我的信息 → **学籍信息** → 页面**顶部**那条隐私提示（正文是「身份证号、考生号、
  家庭住址、邮编已默认遮蔽。」），同样三处都点。

**期望**：三处都能切换；② 切换后下面字段跟着展开/遮蔽，且提示文案本身也换。

**不通过说明什么**：只有点开关本体才响应 → 整行 `toggleable` 丢了，
只剩 `Switch` 自己的小热区（这是「能编译、界面正常、行为退化」的典型）。
另外 ② 的 `Switch` 必须传 `onCheckedChange = null`，否则开关和整行会各接一次点击 → **一下点两回**（切了又切回去）。

### 2-4 底部导航：选中态**换形状**，不只换颜色

**操作**：四个 Tab 来回切。

**期望**：未选中是**描边**（outlined）图标，选中是**实心**（filled）图标。

**不通过说明什么**：只有颜色变、形状不变 → 图标配对丢了。
这条对色觉障碍用户有实际意义，所以单独验收。

### 2-5 选课页内层切换是 pill 指示器

**操作**：选课页 → 「课程 / 抢课任务」。

**期望**：选中项底下一个**胶囊形**指示器（M3 `PrimaryTabRow`），不是细下划线。

### 2-6 成绩页标签仍然**清晰可读**（这处是刻意不统一的）

**操作**：成绩页，找带标签的行（不及格 / 补考）。

**期望**：标签文字**读得出来**（半透明底色 + 深色字的组合）。

**不通过说明什么**：出现「深底深字」→ 容器色/内容色配错。这类错的可怕之处是
**两个颜色各自合法**，编译器和运行时自检都不报 —— 这也是 `verify_ui_controls.py` 存在的原因。

## 3. P2 —— 设置页行归位（M3 `ListItem`）

### 3-1 首页四个分组的入口行：颜色分三层，不是一层灰 ★ 最重要

**操作**：我的（首页），从上往下看「我的信息 / 设置 / 会话与维护 / 其他」四组、共 **12 行**。

**期望**：
- 左侧图标是**主色**（不是灰的）；
- 标题是正常前景色、**加粗适中**；
- 下面那行摘要是**次要色**（比标题淡，但比「禁用」明显）。

**不通过说明什么**：图标和摘要塌成同一个灰色 → `ListItem` 的槽位配色没显式给
（它的默认值全走 `onSurfaceVariant`）。三层色是 Pixel 设置页的形态，也是「一眼看清主次」的底线。

### 3-2 点**整行任意位置**都能进子页（含最右边箭头那一带）★ 最容易漏

**操作**：任取一行，分别点 ① 图标 ② 标题文字 ③ 右侧箭头 **正上方/正中间** ④ 最右边缘空白。

**期望**：四处都能进对应子页。

**不通过说明什么**：只有文字那一块能点、箭头浮在行中间 → `ListItem` 漏了 `fillMaxWidth()`
（它内部**不撑满宽度**）。这个缺陷我是在写进代码前自己抓到的，
`verify_ui_controls.py` §5 和探针各有一条守着它 —— 但**只有真机能证明守住了**。

### 3-3 行高与之前一致 + 两处**有意**的变化

**操作**：对比 P2 前后（或凭印象）。

**期望**：
- **行高基本不变**（原来手算 60dp，M3 两行 `ListItem` 也是 60dp）；
- **左右内边距从 14dp 变 16dp**（略宽一点，这是有意的）；
- **分组标题与卡片内的图标左对齐**（标题原来偏左 4dp，现在 16dp）；
- **行间分隔线比之前略明显**（`outline@15%` → M3 默认 `HorizontalDivider`，有意）。

**不通过说明什么**：行高明显变高/变矮 → 摘要为空的那几行被当成了两行排版
（`supportingContent` 应该是 `null` 而不是空 lambda）。

## 4. P3 —— 顶栏（「我的 / 成绩 / 选课」加，课表页刻意不加）

> 这一节的**全部结论都只能靠真机**：静态断言能证明「`nestedScroll` 接线写了」，
> 但证明不了「顶栏真的会折叠」—— 那要 M3 的滚动竞态真的跑起来。

### 4-1 课表页**必须没有**顶栏，且高度与之前一模一样 ★ 最关键的一条

**操作**：切到课表 Tab，对比 P3 之前（或与截图）——看最上面是不是「学期选择 + 回到本周」，
课表格子区从原来的位置开始。

**期望**：**课表页顶层没有任何新增的标题栏**；11 节的滚动高度、表头位置、格子尺寸全部不变。

**不通过说明什么**：多出一条「课表」标题栏 → 有人在 `AppRoot` 里加了统一的 `topBar`
（那样四个 Tab 会一起加），或直接给 `TimetableScreen` 加了 —— **这个取舍是你拍板定的
（课表要竖着滚 11 节，不让出 64dp）**，静态断言 §6 有两条守着，真机再确认一次。
另外：如果课表区整体下移了 64dp，那 4 个像素脚本的截图基准就得重标（本来不用）。

### 4-2 三个主页的顶栏 + 折叠 ★ 核心行为

**操作**：分别进「我的」「成绩」「选课」，各做一次：**向下滑到底 → 再往回滑一点 → 停在中间**。

**期望**：
- 顶栏标题分别是 **我的 / 成绩 / 选课**（不是串了别的页的标题）；
- **向下滑：顶栏收起并完全让出高度**（内容顶到状态栏下面）；
- **往回滑一点：顶栏立刻收回来**（`enterAlways` 的行为，不用滑到顶）。

**不通过说明什么**：
- 顶栏**一直不动** → 折叠接线漏了/断了。这是最典型的静默失效：不报错、界面正常、特性等于没有。
  静态断言 §6 有一条查「三个主页都把折叠接到了页面根容器」，探针里另有两条变异守它；
- 顶栏收起来了但**内容没跟着上移**（留一条 64dp 空白）→ 折叠没让出布局高度；
- 切 Tab 之后发现**新页面的顶栏是收着的** → 三个页面共用了同一个折叠状态（应该各自 `remember`）。

### 4-3 顶栏与状态栏之间**不能**出现一条空白或色带

**操作**：三个主页各看一眼顶部（浅色主题最容易看出色带）。

**期望**：状态栏那一条的颜色与顶栏**同一个颜色**，顶栏标题紧贴状态栏下方（不留额外空白）。

**不通过说明什么**：
- 顶栏上方多出一条空白（约一个状态栏高）→ 顶栏又吃了一次系统内边距（`windowInsets` 没置 0）；
- 状态栏那一条与顶栏**颜色差一档**（一条横向色带）→ 顶栏容器色没跟 `Scaffold` 对齐
  （`surface` vs `background`）。

### 4-4 子页：顶栏是 M3 的，且**返回按钮不会滑走**

**操作**：我的 → 学籍信息（或任选一个子页）：
① 看顶栏形态；② **把内容往下滑**，看返回按钮在不在。

**期望**：
- 顶栏是 M3 的标题栏样式：标题比之前**大**（M3 顶栏标题是 22sp，原来是 16sp）、
  整条高 64dp（原来是 54dp）—— 这是**有意**的，就是「要像 Pixel」的那部分；
- 左上角返回按钮一直都在（子页顶栏**固定不动**），点它能返回；
- 「我的」页首页与子页**不会同时出现两条标题栏**。

**不通过说明什么**：出现两条标题栏 → 「我的」页 Hub 的顶栏没有随子页切换而让位；
返回按钮会滑走 → 子页顶栏错接了折叠行为（用户得先往回滚才能退出，这是最不该藏的控件）。

### 4-5 十二个子页都还在（顺手扫一遍）

**操作**：诊断与日志 → 看自检 `=== 全部自检：X/Y 通过 ===`，**X 必须等于 Y**；
再随手进两个子页确认都有标题栏与返回按钮。

**期望**：自检全绿；每个子页都有标题栏 + 可用的返回。

**不通过说明什么**：某个子页没有标题栏/返回按钮 → 它没走 `DetailScaffold`。
静态断言查了「12 处调用点仍在」，但真机扫一眼更直接。
